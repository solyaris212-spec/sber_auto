# Проект: Анализ сайта СберАвтоподписка

## Описание
Цель данного проекта — создать модель машинного обучения для прогнозирования вероятности того, что посетитель сайта совершит целевое действие - оставит заявку.

## Для каких целей можно использовать эту модель:
- Оценить эффективность рекламных каналов
- Улучшить пользовательский опыт на сайте
- Даёт основу для A/B-тестов: «А что если изменить текст на странице? Модель покажет, выросла ли вероятность заявки»

## Модель анализирует:
- Откуда пришел пользователь (источник трафика)
- Какое устройство использует (телефон/компьютер)
- Какие страницы смотрел
- Сколько времени провел на сайте

## Точность модели

- **ROC-AUC: 0.91**, целевой показатель: 0.65
- Модель может отсеять ~60% посетителей, которые точно не оставят заявку (экономия ресурсов). Но из оставшихся 40% только каждый пятый реально рсиавит заявку (нужна дополнительная фильтрация менеджерами).

## Требования

## Установка

1. Скачайте sber-auto-prediction.zip и распакуйте.
2. Зпустите командную строку в распакованной директории.
3. Создайте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   # или
   venv\Scripts\activate  # Windows

4. Установите зависимости:
   pip install -r requirements.txt

5. Убедитесь, что в текущей директории находятся следующие файлы артефактов модели:
predict_api.py — файл с запуском сервера
final_model_step3_4.pkl — обученная модель
preprocessor.pkl — препроцессор признаков
feature_info.pkl — метаданные признаков
optimal_threshold.pkl — порог классификации

7. Запустите сервер:
uvicorn predict_api:app --host 0.0.0.0 --port 8000
### или
python predict_api.py

8. Сервер будет доступен по адресу: http://0.0.0.0:8000

9. Перейдите по адресу: http://127.0.0.1:8000/docs
Там вы увидите интерактивную документацию Swagger, где можно:
Увидеть все доступные эндпоинты
Протестировать API прямо из браузера
Увидеть структуру запросов и ответов.

11. Перейдите по адресу: http://127.0.0.1:8000/health
Это покажет, что сервис работает корректно и модель загружена.

12. Узнать предсказание модели: 
Откройте http://127.0.0.1:8000/docs
Найдите POST /predict
Нажмите "Try it out"
Введите тестовые данные в формате JSON
Нажмите "Execute"
