# Проект: Анализ сайта СберАвтоподписка

## Описание
Цель данного проекта — создать модель машинного обучения для прогнозирования вероятности того, что посетитель сайта совершит целевое действие - оставит заявку.

## Для каких целей можно использовать эту модель:
- Оценить эффективность рекламных каналов
- Улучшить пользовательский опыт на сайте
- Даёт основу для A/B-тестов: «А что если изменить текст на странице? Модель покажет, выросла ли вероятность заявки»

## Модель анализирует:
- Откуда пришел пользователь (источник трафика)
- Какое устройство использует (телефон/компьютер)
- Какие страницы смотрел
- Сколько времени провел на сайте

## Точность модели

- **ROC-AUC: 0.91**, целевой показатель: 0.65
- Модель может отсеять ~60% посетителей, которые точно не оставят заявку (экономия ресурсов). Но из оставшихся 40% только каждый пятый реально рсиавит заявку (нужна дополнительная фильтрация менеджерами).

14. Дополнительная информация
###  Перечень полей для заполнения:

1. Параметры трафика (UTM-метки)/ Эти строки описывают, откуда пришел пользователь.

- utm_source: Источник трафика (например: "yandex", "google", "vk", "direct").
- utm_medium: Тип трафика (например: "organic", "cpc", "referral", "social", "email").
- utm_campaign: Название рекламной кампании (например: "summer_sale", "brand_search").
- utm_adcontent: Идентификатор объявления или креатива.
- utm_keyword Ключевое слово, по которому кликнули.
2. Характеристики устройства

Данные о том, с какого устройства зашел пользователь.
- device_category: Тип устройства ("desktop", "mobile", "tablet").
- device_os: Операционная система (например: "Windows", "iOS", "Android", "macOS").
- device_brand: Бренд устройства (например: "Apple", "Samsung", "Xiaomi", "Unknown").
- device_browser: Браузер (например: "Chrome", "Safari", "Firefox").
- device_screen_resolution: Разрешение экрана в формате "ШиринаxВысота" (например: "1920x1080", "375x812").

3. География
- geo_country: Страна (например: "Russia").
- geo_city: Город (например: "Moscow", "Saint Petersburg").

4. Время визита (Необязательно, но рекомендуется)
- visit_date: Дата в формате "YYYY-MM-DD" (например: "2023-10-25").
- visit_time: Время в формате "HH:MM:SS" (например: "14:30:00").

5. Поведенческие метрики (Числовые)

Агрегированные данные о поведении пользователя в текущей сессии.
- visit_number: Порядковый номер визита пользователя (например: 1, 3, 10).
- hit_count: Общее количество действий (просмотров) в сессии.
- unique_pages: Количество уникальных страниц, которые посетил пользователь.
- event_count: Количество зарегистрированных событий (клики, скроллы и т.д.).
- avg_time_between_hits: Среднее время между действиями в секундах (например: 15.5).

### Параметры ответа

- prediction - бинарное предсказание: 0 (нет заявки) или 1 (будет заявка)
- probability - вероятность положительного класса (0.0–1.0)
- threshold - порог классификации, использованный для бинарного решения
- latency_ms - время обработки запроса в миллисекундах
- timestamp - временная метка ответа в формате ISO 8601
- warning -дополнительное предупреждение, если есть.
